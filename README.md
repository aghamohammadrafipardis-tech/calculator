# 🧮 Windows Forms Calculator

A simple and interactive Calculator application built with **C#** and **Windows Forms (.NET Framework)**. 

## ✨ Features
- Basic arithmetic operations: Addition (`+`), Subtraction (`-`), Multiplication (`*`), and Division (`/`).
- **Keyboard Support**: You can use your Numpad or the top row numbers on your keyboard to type.
- **Status Bar**: A dynamic label that shows the current state of the operation.
- **Error Handling**: Prevents crashing on invalid inputs like dividing by zero.
- Clear (C) and Clear Entry (CE) functionality.

## 🛠️ Technologies Used
- **Language**: C#
- **Framework**: .NET Framework 4.6.1
- **GUI**: Windows Forms (WinForms)
