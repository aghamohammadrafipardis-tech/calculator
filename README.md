
# 🧮 Windows Forms Calculator

A desktop calculator application developed using C# and Windows Forms, designed to perform basic mathematical operations through a graphical user interface.

## 🎯 Problem

Performing basic mathematical calculations is a common everyday task. A simple calculator application provides users with an accessible way to perform calculations without requiring manual computation.

This project demonstrates the development of a desktop application using C# and Windows Forms.

## ✨ Features

- **Graphical User Interface:** Simple and interactive calculator interface.
- **Addition:** Perform addition operations.
- **Subtraction:** Perform subtraction operations.
- **Multiplication:** Multiply numerical values.
- **Division:** Divide numerical values.
- **Clear Function:** Reset the current calculation.
- **User Interaction:** Handle button clicks and user input.
- **Calculation Display:** Show entered values and calculation results.
